# v0.2.5.1 ASR 技术验证记录

## 当前状态

本阶段建立统一 ASR 转录接口、离线 benchmark 骨架和独立的 MLX 适配器，
不接入音频下载、字幕回退或现有 pipeline。

当前正式基线为 v0.2.4：

- `main`、`origin/main` 和 `v0.2.4` 指向 `f9ac1d6c1ea69d0b53dab6949cfe3beec9070e2c`。
- v0.2.4 验收记录为 `183 passed`。
- 现有 `Transcript` 已支持 `source="asr"`，本阶段复用该数据模型。

## 接口决策

`transcriber.py` 只暴露任务层需要的最小接口：

```python
transcribe(audio_path, *, language=None) -> Transcript
```

引擎专属的 device、compute type、beam size 等参数不进入 pipeline。一次任务创建一个 Transcriber 实例，再连续处理多个分 P；`benchmark_transcriber_reuse` 会严格只调用一次工厂并记录 Transcriber 创建耗时、单样本耗时和总耗时。创建耗时不等同于模型加载耗时，尤其是 MLX 适配器采用延迟加载时。

当前已增加独立的 `mlx_transcriber.py` 适配器，但尚未绑定到现有 pipeline。
适配器内部固定当前暂定推荐的 `mlx-community/whisper-small-mlx`，只向任务层
提供统一 `Transcriber` 方法；`faster-whisper` 仍不进入正式运行依赖。

## 自动化验证

自动化测试使用临时文件和 fake Transcriber，完全离线覆盖：

- mapping/object 两种分段结果转换。
- ASR 来源和 language 标记。
- 空结果、缺字段、非法时间轴和空文本拒绝。
- 多个样本只创建一次 Transcriber 并连续复用。
- benchmark 样本路径和空样本校验。
- MLX 适配器的分段转换、语言传递和模型配置封装。

## 候选引擎本机实测

当前已在独立的 `.venv-asr` 验证环境安装候选包，并下载同量级 `small` 模型到本机 Hugging Face 缓存：

- `mlx-whisper==0.4.3`，模型 `mlx-community/whisper-small-mlx`，缓存约 459 MB。
- `faster-whisper==1.2.1`，模型 `Systran/faster-whisper-small`，缓存约 464 MB。

使用 2 秒静音 NumPy 音频完成了安装和重复调用 smoke test。该结果只能证明模型可加载和接口可调用，不能作为中文准确率或长音频性能结论：

| 引擎 | 首次调用 | 第二次调用 | smoke test 峰值内存 | 备注 |
|---|---:|---:|---:|---|
| faster-whisper（CPU int8） | 1.349 秒 | 1.081 秒 | 约 1191 MB | 返回 `zh`，两次均有 1 个分段 |
| mlx-whisper（Apple Metal） | 2.057 秒 | 0.284 秒 | 约 853 MB | 返回 `zh`，两次均有 1 个分段 |

路径输入方式的 mlx-whisper smoke test 还发现当前环境没有系统 `ffmpeg`；使用内存 NumPy 音频可以正常调用。本阶段不据此决定最终音频格式，后续音频获取阶段再处理该依赖。

## 公开样本 benchmark

使用 yt-dlp 下载了两个公开 B 站视频的音频到 `/private/tmp/bilibili-asr-benchmark/`，没有下载画面，也没有写入仓库：

- `BV1Li2jBdEzS`：约 5:17，音频文件约 3.54 MiB。
- `BV1r3411Q7Rr`：约 36:03，音频文件约 28.84 MiB。

使用同一个 `small` 模型实例/进程连续处理两个样本，结果如下。RTF 越低越快：

| 引擎 | 5:17 耗时 / RTF | 36:03 耗时 / RTF | 峰值内存 | 备注 |
|---|---:|---:|---:|---|
| faster-whisper（CPU int8） | 67.188 秒 / 0.2121 | 411.700 秒 / 0.1903 | 约 4060.6 MB | 模型本地加载约 0.413 秒；同一实例连续处理 |
| mlx-whisper（Apple Metal） | 17.127 秒 / 0.0541 | 108.454 秒 / 0.0501 | 约 1280.6 MB | 同一进程连续调用；第一次样本包含模型首次加载成本 |

两条视频的匿名字幕接口均提示“Subtitles are only available when logged in”，因此没有下载到可作为真值的字幕文件。当前只能确认速度、内存、中文语言识别和输出稳定性，不能据此计算可靠的 CER/WER 或专业术语准确率。

### 当前判断

在当前 Apple Silicon 开发机上，暂定推荐 `mlx-whisper + mlx-community/whisper-small-mlx`：
速度约为 faster-whisper 的 3.7–3.8 倍，峰值内存约低 68%。这是基于当前机器的
性能和资源占用推荐，不代表准确率更高；准确率仍未完成定量验证。

本阶段不因准确率暂缓而接入生产 pipeline；后续 v0.2.5.3/v0.2.5.4
仍需进行中文语音、专业术语和时间戳的人工验收。README 未更新为已支持 ASR。
